# 开源核心范围

HiEnglishLab Diagnosis Framework 采用 Open Core 模式。本仓库是公开的学习证据处理基础层，不等同于完整、经过验证或商业化的诊断系统。

## 本仓库公开的内容

- 版本化、厂商中立的证据与报告数据格式。
- 本地 CLI 和 Python 确定性分析接口。
- 基础、可解释的描述性指标。
- 合成示例、测试、隐私保护措施和威胁模型。
- 不执行不可信插件代码的安全扩展接口。
- 社区维护的文档和翻译。

## 不属于本仓库的内容

以下能力可以独立开发和维护，不承诺作为开源组件发布：

- 专有评分权重、阈值和校准方法。
- 常模数据、已标注学习者语料和纵向成长基准。
- 经过验证的 KET、PET、IELTS 或其他考试适配包。
- 个性化教学处方、课程路径和进步模型。
- 商业报告、后台、集成、运营及支持流程。
- 私有评测集、Prompt、红队案例和质量控制流程。

## 考试与能力等级声明

当前开源核心不会给出 CEFR 等级、Cambridge English 考试分数、IELTS Band 或同类资质结果。基础指标可以辅助人工分析，但不能替代官方任务、受训考官、经过验证的评分流程或对听、说、读、写的完整评价。

未来任何公开的考试映射都必须：

1. 引用当时有效的官方公开资料；
2. 区分可观察证据与推断出的能力；
3. 公开验证方法和局限；
4. 不复制受版权保护的考试内容或保密评分材料；
5. 不暗示得到考试机构认可或存在合作关系。

Cambridge、KET、PET、IELTS 及相关标识属于各自权利人。本项目与 Cambridge University Press & Assessment、British Council、IDP 或 IELTS 合作方不存在隶属或认可关系。
